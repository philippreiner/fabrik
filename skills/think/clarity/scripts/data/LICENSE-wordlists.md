# Word lists

`common_en.txt` (top 15,000 English word forms) and `common_de.txt` (top 20,000 German word forms) are exported from wordfreq 3.1.1 by Robyn Speer, filtered to alphabetic tokens, most frequent first.

- Source: https://github.com/rspeer/wordfreq
- Data license: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). These derived lists carry the same license.
- wordfreq's data is frozen at about 2021, before LLM-generated text spread widely.
